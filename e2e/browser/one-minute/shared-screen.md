# The one-minute path: with a shared screen

Written by `e2e/browser/one-minute.spec.ts`. Do not edit this file by hand.
Run `pnpm e2e:browser -g one-minute` and commit the file it writes.

The tables count screens, taps and typed fields between the landing page and
the first game phase. A step added to that path changes a number here, so
review sees it as a diff.

Budget: 60 seconds, from the first tap to the first game phase (goal 1).
Cost model: 3 seconds for a tap, 6 seconds for a typed field.
A room code read aloud, a wait on the network, and a screen with no control on
it cost nothing.

| who | screens | taps | typed fields | cost |
| --- | --- | --- | --- | --- |
| host (TV) | 6 | 1 | 0 | 3s |
| starter (phone) | 6 | 4 | 2 | 24s |
| joiner (phone) | 6 | 2 | 2 | 18s |

The room reaches its first game phase after the TV's walk and then the starter's, so they
add up: 27s. Anyone else joins while the starter waits in the lobby, so the joiner's
walk runs alongside theirs.

Fits the 60s budget.
